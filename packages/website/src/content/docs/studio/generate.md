Create Tasks from real Stories once your Template is ready. Studio previews the run against Azure DevOps first and asks for confirmation before it creates anything.

Before you start, [set up a Connection Profile](/connections/profiles/#atomize-studio). Try the Template offline with [Mock Preview](/getting-started/studio/) first if you have not already.

## If something goes wrong

Rejected tokens, missing permissions, and Azure DevOps errors are covered in [Fix connection problems](/connections/troubleshooting/). If Generate is unavailable because the companion process stopped, see [Companion Process Recovery](/studio/settings-recovery/#companion-process-recovery).
