Look up exact names from your Azure DevOps project while you author, instead of typing them from memory. Both browsers read through a [Connection Profile](/connections/profiles/#vs-code) and copy the value to the clipboard.

<!-- atomize:include vscode-browsers -->

## Use the copied values

Paste a field reference name into custom fields, conditions, or the estimation source, and a query path into `filter.savedQuery`. Check exact types and rules in the [Schema Reference](/reference/templates/schema/#template.filter.savedQuery). When you are ready, [generate Tasks](/vscode/generate/).
